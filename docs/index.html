Search efficiently for exact matches and by meaning

exact matches come first finds translations and paraphrases explains every rank runs in the browser, Bun and Node.js

Lexical and vector retrieval, fused into one ranking. Exact matches rank first, translations still match, and every hit explains its rank. This search runs isomorphic. No search server required, but you can run defuss-search in Node.js or Bun as well.

Why defuss-search

§What a hybrid ranking gives you

Exact where it matters

With exact: 'promote', an exact match on a symbol or ID ranks first, whatever the vectors say.

Fusion or a cascade

Weighted reciprocal rank fusion of both top-25 lists, or one source rescoring the other, chosen per query.

A neural stage you can switch off

searchPreset('reranked') lets ColBERT reorder the top 25 unless both sources agree on a clear winner; 'efficient' skips it and reaches the same R@1.

Every rank explained

Each hit carries its rank and score per source, the fusion terms and the reason for any promotion.

Small core, optional peers

No runtime dependencies; ESM and CommonJS with types. Adapters load only when you import them, and your own retrievers plug in the same way.

20 languages, measured

Per-language analyzers and multilingual vectors, with R@1 to R@25 published for every language.

How it works

§Retrieve twice, fuse once, rerank only when needed

Both retrievers return their top 25. Pure functions fuse them, promote exact matches and keep both sources represented; a gate decides whether ColBERT reorders the top 25.

Select a box or a wire to see what it touches; the toolbar replays the steps.

Nothing in this picture is a server: the index, the models and the ranking live where your code runs.

Fusion default

Both sources retrieve independently; a document only one of them finds can still win.

Vector first

Semantic candidates, ordered by the lexical index.

Lexical first

Lexical candidates, rescored by vector similarity.

§The ranking contract, in order

The final rank is authoritative; scores from different stages are not comparable, so each hit states its scoreKind.

  • every search
  • an option you set
  • with a reranker
  1. retrieveeach source returns its top 25 among the eligible IDs
  2. fuseweighted reciprocal rank fusion, or the second stage of a cascade
  3. exactwith exact: 'promote', literal matches move to the front
  4. coveragebalance reserves early ranks for each source's best candidate
  5. gatea clear vector winner that lexical retrieval agrees with skips the reranker
  6. rerankColBERT reorders the top 25; exact promotion and coverage apply again
  7. pageranks are assigned before the page is cut

For teams and enterprises

Search adapted to your data, your languages and your rules

defuss-search stays open source and free. When your data needs more than the presets, its author adapts and tunes it with your team, measured on your own queries.

  • Tuned on your queries. An evaluation set from your documents, with R@k before and after.
  • Your vocabulary and languages. Product codes, part numbers, legal terms, mixed languages.
  • Private by design. In the browser, on your servers or air-gapped.
  • Into what you already run. Adapters for your indexes, models and application.

§ Vibe coding

Paste this prompt into your coding agent; it points to the current README. 

Integrate defuss-search into this app: https://github.com/kyr0/defuss-search
Install defuss-search with its peers defuss-lexicalsearch and defuss-vectorsearch, and read the README first. Build the index with createHybridIndex({ documents, vectors, reranker, defaults: searchPreset('reranked') }) from defuss-search/indexing, or connect existing indexes with createLexicalRetriever, createVectorRetriever and new HybridSearch({ lexical, vector, reranker }).
Embed documents and queries with the same model; defuss-vectorsearch's Winzling-embed runs in the browser. Pass exact: 'promote' so a query that equals a symbol or ID field ranks that document first.
The reranker wraps a ColBERT model with createColbertAdapter from defuss-search/colbert; the reranked preset skips the model when both sources agree. Without a reranker, use searchPreset('efficient').
