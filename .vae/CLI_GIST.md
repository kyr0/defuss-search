# CLI gist

- VERIFIED[CPU integration] `bun run test:models:bun` and `bun run test:models` load SHA-verified Winzling and ColBERT assets; BC v0.3.0 reports in `output/live-bun.json` and `output/live-node.json`.
- VERIFIED[WASM integration] `bun run test:wasm:bun` and `bun run test:wasm` run the real browser entry in CLI runtimes; BC `output/live-wasm-bun.json` and `output/live-wasm-node.json`.
- VERIFIED[model cache] `DEFUSS_MODEL_DIR=/absolute/path bun run models` reuses verified assets; BC `scripts/models.mjs` and `output/model-assets.json`. An unset value uses .models.
- VERIFIED[recall bench] `make bench` runs `bench/recall.mjs` on Bun and Node.js, `bench/recall-browser.mjs` in Chromium (Bun only: it uses Bun.build), `bench/language-guess.mjs` (ColBERT pairs cached in input/), then the frontier and `scripts/recall-report.mjs`; BC `output/bench/recall-{bun,node,chromium}.json` and `docs/data/recall.json` on 2026-10-31, 2026-11-06. The first run embeds 3,000 texts (~4 min CPU) into `input/multilingual-vectors.json`.
- VERIFIED[local ports] `make e2e` and `make start` bind 127.0.0.1; a sandbox without local binding fails `make start` with "Failed to start server", and an occupied PORT does too; `PORT=0` picks a free port; BC session 2026-10-31.
- VERIFIED[dev server] `make dev` runs in the foreground; a `website/` edit rebuilds in ~30 ms, a `src/` edit adds pkgroll (~0.8 s), then open pages reload via `/__reload`; port 4173 was held by another repo's `scripts/serve.mjs`, so use `PORT=0 make dev`; BC probes 2026-11-01.
- VERIFIED[demo] `make e2e` drives the demo at `?models=off` (no model request, efficient parity in ~7 s); `DEFUSS_LIVE_BROWSER=1 make e2e` loads the WASM models from Hugging Face and recomputes reranked parity (885 ColBERT calls, ~2 min); `make bench` rewrites `docs/data/{corpus.json.gz,vectors.bin.gz,tokens.bin.gz,manifest.json}` via `scripts/demo-data.mjs` (`bun scripts/demo-data.mjs` alone takes ~2 s with cached embeddings and ColBERT matrices); BC runs 2026-11-01, 2026-11-02. Full-page screenshots show scroll-reveal sections blank; capture an element after `scrollIntoViewIfNeeded`.
- VERIFIED[surface bench] `bun run bench:surface` (~20 s with cached embeddings) writes `output/bench/surface.json`: stemmed fields vs `withSurfaceFields` companions on Belebele, notes and the defuss-shadcn docs; BC run 2026-11-02.
- VERIFIED[pages] GitHub Pages deploys from `.github/workflows/pages.yml` (build_type workflow since 2026-11-02), on push to main or `gh workflow run pages.yml`; the branch's `docs/` lacks the gitignored `docs/assets/ort/`, so a branch deploy breaks every model load; BC run 41383735551 and a live Chromium probe 2026-11-02. Pages caches files 10 min: `scripts/website-build.mjs` keeps the worker chunk-free and stamps `?v=<build>`; a browser that saw a 404 chunk before that fix needs one reload after the deploy.
